# Claude Skills によるタスク管理ガイド

AI Task Manager を Claude Code と連携させて、タスク管理を自動化する方法を説明します。

## 概要

Claude Skills 機能により、Claude Code に以下のことを依頼できます：

- 毎日のタスク確認と整理
- 期限が近いタスクのチェック
- プロジェクト進捗レポートの生成
- タスクの自動整理（タグ付けなど）

---

## セットアップ

### 1. プロジェクトの準備

AI Task Manager がインストールされていることを確認します：

```bash
cd /path/to/AITaskManager
python3 -m ai_task_manager.cli --version
```

### 2. スクリプトに実行権限を付与

```bash
chmod +x scripts/*.py
```

### 3. スクリプトの動作確認

各スクリプトを手動で実行して動作を確認します：

```bash
# 毎日のタスク確認
python3 scripts/daily_review.py

# 期限チェック
python3 scripts/deadline_check.py

# 進捗レポート
python3 scripts/progress_report.py

# 自動整理
python3 scripts/auto_organize.py
```

---

## 利用可能なスクリプト

### 1. daily_review.py - 毎日のタスク確認

**機能**:
- 今日期限のタスクを表示
- 期限超過タスクを警告
- 進行中のタスクを一覧表示
- 全体統計サマリーを表示

**使い方**:
```bash
python3 scripts/daily_review.py
```

**出力例**:
```
================================================================================
🔍 今日のタスク確認を開始します
================================================================================

📅 今日期限のタスク
--------------------------------------------------------------------------------
⚠️  2件のタスクが今日期限です:

  🔄 プロジェクトA - フェーズ2実装
     ID: 12 | 優先度: high | 進捗: 75%
     タグ: urgent, important

  ⏸️ ドキュメント更新
     ID: 15 | 優先度: medium | 進捗: 0%

🚨 期限超過タスク
--------------------------------------------------------------------------------
⚠️  3件のタスクが期限超過しています:

  🔴 バグ修正 #456
     ID: 8 | 期限: 2026-01-10 (6日超過)
     優先度: high | 進捗: 30%
```

### 2. deadline_check.py - 期限チェック

**機能**:
- 今後N日以内（デフォルト: 3日）に期限のタスクをチェック
- 緊急度に応じて色分け表示
- 進捗が遅れているタスクを警告

**使い方**:
```bash
# デフォルト（3日以内）
python3 scripts/deadline_check.py

# 7日以内のタスクをチェック
python3 scripts/deadline_check.py 7
```

**出力例**:
```
================================================================================
⏰ 期限チェックを開始します
================================================================================

⚠️  4件のタスクが3日以内に期限です:

🔴 【本日】 レポート作成
     ID: 20 | 期限: 2026-01-16
     優先度: high | 進捗: 85%
     カテゴリ: Work

🟡 【明日】 会議準備
     ID: 21 | 期限: 2026-01-17
     優先度: medium | 進捗: 40%
     ⚠️ 注意: 進捗が40%で期限が迫っています！
```

- カテゴリ別進捗状況
- 優先度別統計

- タスク階層の表示

**使い方**:

================================================================================

  完了         : 8 件 (66.7%)

### 4. auto_organize.py - 自動整理

**機能**:
- 期限超過タスクに「overdue」タグを自動追加
- 3日以内に期限のタスクに「urgent」タグを自動追加
- 完了後30日以上経過したタスクに「archived」タグを自動追加
- 不要なタグを自動削除

**使い方**:
```bash
python3 scripts/auto_organize.py
```

**出力例**:
```
================================================================================
🔧 タスクの自動整理を開始します
================================================================================

📌 期限超過タスクの処理...
  ✅ タスク 5: バグ修正 に「overdue」タグを追加
  ✅ タスク 8: テスト実装 に「overdue」タグを追加

⚡ 緊急タスクの処理...
  ✅ タスク 12: レポート作成 に「urgent」タグを追加

🗑️  不要なタグのクリーンアップ...
  ✅ タスク 3: 完了済みタスク から「overdue」タグを削除

================================================================================
📊 整理結果サマリー
================================================================================
  期限超過タグ追加   : 2 件
  緊急タグ追加       : 1 件
  アーカイブタグ追加 : 0 件
  不要なタグ削除     : 1 件
```

## Claude Code との統合

### Claude Code でスクリプトを実行

Claude Code に自然言語で依頼してスクリプトを実行できます：

**例1: 毎日のタスク確認**
```
"今日のタスクを確認して"
"今日やるべきことを教えて"
```

**例2: 期限チェック**
```
"期限が近いタスクを教えて"
"今週中に期限のタスクをチェックして"
```

**例3: 進捗レポート**
```
"プロジェクトの進捗状況を見せて"
"Workカテゴリの進捗をレポートして"
```

**例4: 自動整理**
```
"タスクを整理して"
"期限超過タスクにタグを付けて"
```

### エイリアスの使用

`.claude/config.yaml` で定義されたエイリアスを使用できます：

```bash
# ai-task-manager コマンドのエイリアス
tm list
task tree
tl              # tm list のショートカット
ta "新規タスク"  # tm add のショートカット
```

## 自動実行（スケジュール）

`.claude/config.yaml` で設定されたスケジュールに従って自動実行されます：

- **daily-review**: 毎日 9:00 AM
- **deadline-check**: 毎日 9:00 AM と 5:00 PM

**注意**: 自動実行には Claude Code の環境設定が必要です。

## トラブルシューティング

### スクリプトが実行できない

1. 実行権限を確認:
```bash
ls -l scripts/*.py
chmod +x scripts/*.py
```

2. Python パスを確認:
```bash
which python3
python3 --version
```

3. PYTHONPATH を設定:
```bash
export PYTHONPATH=/path/to/AITaskManager:$PYTHONPATH
```

### タスクが取得できない

1. データベースが存在するか確認:
```bash
ls -l data/tasks.db
```

2. CLI コマンドが動作するか確認:
```bash
python3 -m ai_task_manager.cli list
```

### タグが追加/削除できない

`update` コマンドの権限を確認:
```bash
python3 -m ai_task_manager.cli update 1 --add-tags test
```

## カスタマイズ

### 警告日数の変更

`deadline_check.py` の警告日数を変更できます：

```bash
# 7日以内の期限をチェック
python3 scripts/deadline_check.py 7

# 1日以内（明日まで）
python3 scripts/deadline_check.py 1
```

### アーカイブ期間の変更

`auto_organize.py` の `archive_date` を編集して、アーカイブ対象期間を変更できます：

```python
# デフォルト: 30日
archive_date = today - timedelta(days=30)

# 60日に変更
archive_date = today - timedelta(days=60)
```
